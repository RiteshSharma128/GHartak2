## ✨ Features

- User Authentication
- Product Browsing
- Category Filtering
- Search Products
- Cart Management
- Wishlist Support
- Order Placement
- Address Management
- Responsive Design
- Multi Role System
- Real Time Updates
- Modern UI/UX
- Mobile Friendly
