# 🛒 GharTak Frontend

Modern grocery delivery platform built with React.js, Vite and Tailwind CSS.

## 🚀 Live Demo

Frontend:
https://ghar-tak2-one.vercel.app/

## ✨ Features

- User Authentication
- Product Browsing
- Category Filtering
- Search Products
- Cart Management
- Wishlist Support
- Order Placement
- Address Management
- Responsive Design
- Multi Role System
- Real Time Updates
- Modern UI/UX
- Mobile Friendly

---

## 🛠 Tech Stack

### Frontend

- React.js
- Vite
- Tailwind CSS
- React Router DOM
- Axios
- React Hot Toast
- Lucide React
- Clerk Authentication
